# Media Backup Server 0.3.0

Server 首次独立仓库版本，包含 Linux x86_64 服务端及管理 Web，不包含 Android/iOS 安装包。
移动端单独在 `isarmg/media-backup-client` 构建与发行。本文件是后续发布说明草稿，不代表 Release 已创建。

产品协议仍由 Server 仓库维护，Client 固定完整协议提交。Server 归档不再含移动 FFI 头文件或绑定移动 ABI 身份。
当前 Schema 与不可变发行身份仍严格验证，不提供旧状态兼容或跨版本恢复；升级以 `sarmg-upgrade` 明确支持矩阵为准。
