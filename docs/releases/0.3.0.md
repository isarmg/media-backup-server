# Media Backup Server 0.3.0

Server 首次独立仓库发行，包含 Linux x86_64 服务端、管理 Web 和配套图库增强。
Android APK 与 iOS IPA 在 [Media Backup Client](https://github.com/isarmg/media-backup-client/releases) 独立发行。

- 时间线支持照片/视频、日期区间和来源设备的全库筛选，资产/资源/标签使用批量 SQL 装配。
- 新增同步水位与 UUID 分页快照，支持客户端首次缓存构建及后续增量更新；批量标签成员变更生成资产事件。
- 新增最长边 1600 像素的派生预览，保留原始媒体内容；不支持的格式回退读取原件。
- 原件接口支持鉴权 Range、HEAD、ETag 条件读取，为视频在线播放提供分段读取能力。
- 保留账户隔离、原有 `/v2` 上传 DTO、plain-v1 存储编码和当前数据库 schema。

57 项 Rust 测试通过；CI 覆盖管理 Web 流程以及真实发行归档构建、部署验证。
下载附件 `media-backup-server-0.3.0-x86_64-unknown-linux-gnu.tar.gz`，并使用 `SHA256SUMS` 核对下载。

当前 schema 与发行身份仍严格验证，不提供产品启动时的旧状态迁移；升级以独立 `sarmg-upgrade` 的明确支持矩阵为准。
