# Media Backup Server 0.3.4

本版本将 Foundation Server 固定升级至 0.7.5，并采用约 328 KiB 的 Maple 首屏字体子集；登录与管理页面不再等待完整 CJK 字体分片，启动超时后也不会在页面已显示后再次切换字体。

启动过渡改为中性的加载指示，不再暴露“恢复会话”文案；平台管理员页面已移除，管理员资料只保留在右上角人物图标的账户设置中。嵌入式 Web 资源同时支持强 ETag 条件请求，未变化资源返回 304 且不重复传输正文。

0.3.4 同步修正正式发行包的 Web 资源与发行契约指纹门禁，确保 CI 生成、验证和安装脚本使用同一不可变身份。
