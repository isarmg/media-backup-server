# xszs 1.0.1

## 自 1.0.0 以来的更新

- 简化存储服务首次安装和配置流程，集中说明运行参数与管理命令。
- 完善存储工作流与发行包内管理手册，包内说明覆盖安装、初始化和运行检查。
- Rust 与内嵌管理 Web 同步采用已验证并锁定的 xcss 1.0.2。
- 打包、安装、启动及部署测试同步使用 1.0.1 目录与程序版本。
- 协议包显式固定为 1.0.0，软件发行号独立升级；数据库格式与存储编码保持不变。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xszs-1.0.1-x86_64-unknown-linux-gnu.tar.gz` 和 `SHA256SUMS`。

安装步骤见[部署指南](../server-release-readme.md)。
