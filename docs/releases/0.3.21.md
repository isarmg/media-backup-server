# media-backup-server 0.3.21

- 管理 Web 的“日志”页默认显示服务器当天的全部管理员审计记录，可按服务器本地日期选择其他日；记录按审计序号倒序显示，不再分页。日期边界按本地午夜计算，时间显示包含 UTC 偏移。浏览器单次响应预算为 64 MiB，请求时限为 120 秒。
- 实例凭据操作和配额输入反馈更加明确。管理页面接受小数 GiB，并将其换算为整数字节；过小的正数输入会被拒绝。
- 校正内嵌 Web 资产的发行身份与运维文档。数据库 Schema 身份保持 `media-backup` 0.3.0 / revision 5。
- Rust 平台组件与八个 Web 包精确锁定 Foundation Server 0.9.2 正式发行。

## 验证

- Rust 测试、严格 Clippy、Web 构建及 Chromium / Firefox 浏览器验收通过；日志验收覆盖大量记录、跨时区和夏令时日期。
