# 管理备份实例

先完成[服务端安装](server-release-readme.md)，通过 HTTPS 打开 `/admin` 并登录。手机端由独立的 [xszc](https://github.com/isarmg/xszc) 提供。

## 连接一部手机

1. 在管理页新建“备份实例”。系统一次创建存储归属、客户端实例、授权码和默认 100 GiB 配额。
2. 打开实例详情，按需要修改名称、存储位置和配额。
3. 在 xszc 输入服务端 HTTPS 根地址与此实例的授权码，按手机提示授予媒体权限。
4. 选择一份测试照片或视频上传。
5. 在手机确认上传结果，在服务端核对容量变化，并从图库读取该资源。

配对成功只说明凭据有效。一次文件上传、提交和读取都成功后，才确认整条路径可用。

## 配额与容量

详情页接受小数 GiB，保存后换算为整数字节；`0` 表示不限。修改时核对磁盘实际可用空间和实例当前用量。
API 支持 0～9007199254740991 bytes，概览的总量、已用和待处理数据来自全局统计，实例列表本身每页最多 50 个。
使用页面提供的上一页/下一页；刷新、创建或删除后从第一页查看最新结果。

## 更换实例授权码

“更换密码”会立即使该实例原有客户端凭据失效，手机需要重新配对。确认目标手机后再提交，并在完成重配后测试一次上传。
请求结果无法确认时，先关闭窗口并刷新实例信息，核对当前授权码再决定下一步，避免重复轮换。

管理员登录密码与手机实例授权码分别管理。修改自己的管理员凭据见[账号设置](account-settings.md)。

## 查询日志

从实例详情进入日志会保留该实例筛选；“全部实例”查看全局记录。日期按服务器本地时区，日期范围包含起止当天。
单页最多 50 条，继续使用页面的分页按钮。排查时记录实例 ID、时间范围、请求 ID 和客户端错误。

## 处理删除和上传问题

删除前确认所选对象和影响范围。API 的 `202` 表示用户可见元数据已删除，文件回收仍在协调处理中；`204` 表示本次物理回收已完成。
先查看状态和协调日志，再决定下一步，避免重复删除或直接清空暂存目录。

上传失败时从手机权限、队列状态、网络和服务端容量入手，按[运维排障](operations.md#故障排查)检查。
