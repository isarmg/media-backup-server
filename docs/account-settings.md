# 修改当前账号

1. 登录后点击顶部右侧人物图标，打开账号设置。
2. 输入需要使用的用户名和当前密码。只改用户名时，保持新密码字段为空；同时改密码时，填写并确认新密码。
3. 保存后，使用新的账号信息重新登录。

保存会使旧会话失效，包括其他浏览器中的会话。账号内部 ID 和业务归属保持不变，此页只修改当前登录账号，不提供新建管理员入口。

实例名称在详情页修改，允许 1–64 个 Unicode 字符，首尾按 Unicode White_Space 裁剪；实例名称与管理员登录用户名分别管理。

用户名采用当前管理员规则：3–64 bytes，小写 ASCII，首尾为字母数字，中间允许点、下划线和连字符。密码校验及输入错误由页面提示。
