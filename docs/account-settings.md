# 修改当前账号

登录管理 Web 后，点击上方菜单栏最右侧的圆形人物图标，输入账号名称和当前密码。需要修改密码时填写并确认新密码；留空则保留原密码。点击“保存账号”后，使用新账号信息重新登录，其他浏览器的旧会话也会失效。

账号名称是登录用户名，不会改变内部账号 ID 或业务数据归属。此入口只修改当前登录账号；系统仅允许一个管理员，不提供创建管理员入口。Media Backup 的备份实例在业务页面独立管理，内部存储归属不是可登录用户。

此功能不改变当前 SQLite Schema 及数据格式身份。更换同一数据合同内的软件版本并重启后可继续使用原数据库，无需清空实例、配置或备份数据。

会话保持修复：并发请求按不同顺序更新活跃时间时不会再误判退出。正常空闲到期和显式注销仍需重新登录。

当前产品 UI 不提供新增管理员入口；账号改名不会改变稳定的内部管理员 ID。若未来需要处理旧版本的
多管理员状态，应由具有精确源/目标身份的离线升级工具完成，不能在当前 Server 启动时隐式转换。
